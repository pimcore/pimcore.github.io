Pimcore Statistics Explorer

Pimcore Statistics Explorer provides a simple statistics tool that can be integrated into your application allowing users to dig into data and create statistic reports.


Sample interface for Pimcore Statistics Explorer

Features in a Nutshell​

  • Statistics Explorer to dig into data and create reports.
  • Two statistic modes:
    • Simple listings.
    • Statistics with calculating metrics and pivot tables.
  • Different chart types for visualization of report data.
  • Supported data backends:
    • Opensearch index.
    • Elasticsearch index.
    • MySQL table.
  • Saving and sharing of report configurations.
  • Statistics Loader to include reports in any custom web pages.
  • Event Tracker for custom event tracking.
  • Integration into Pimcore Custom Reports.
