Subscribers Tab

In the Subscribers tab, you can add one or more subscribers to your configuration. Each subscriber will receive a request with the information set in the Events and Schema tab.

Custom Headers​

You can add custom headers to the request that will be sent to all subscribers. This can be useful if the subscribers require a specific header to be set.

Check connectivity​

Use the button next to the input field to check the connectivity for all subscribers. A basic request will be sent to the subscribers. If any error occurs, it will be displayed in a dialog box as below.

Note: Based on the connection timeout, the dialog can take a while to appear.
