Work with Bookmark Lists

The Bookmark Lists functionality can be accessed from the sidebar menu in the File > Bookmark Lists section.

Create a Bookmark List From the Bookmark Lists Grid​

From the Bookmark Lists grid, you can create new bookmark lists by clicking on Add. You can then sort the newly created list's content by name (by default) or manually (as explained in the Sort a bookmark list's items section below).

The existing bookmark lists are displayed by date of creation by default. You can sort them by criteria (e.g. name or ownership) with a simple click on the top of each column of your grid.

An additional Show All Bookmark Lists in System checkbox is available for admin users. This option allows, for example, managing existing bookmark lists created by a deleted user. Only owned or shared bookmark lists are displayed when this option is not selected.

info

When you add a folder containing elements from an element tree to a bookmark list, only this folder is saved in the list while its child elements are loaded on the fly. The same behavior applies to child elements of Documents and Data Objects. As a consequence, the Item Count grid column only indicates the number of first-level elements of your bookmark list.

Open, Edit and Use an Existing Bookmark List​

With a click on the Open icon in the grid, you can access the selected bookmark list in a newly opened panel on the right (by default). This menu - also distinctive thanks to the bookmark icon - can be merged into the left menu with a click on the arrow icon.

The bookmark lists can be organized in folders as the element trees. You can easily localize the items from your bookmark list in their original tree by right-clicking on them and selecting Show in Tree in the context menu.

You can access an item editor by clicking on it. You also have the possibility to drag an item from the bookmark list directly to a drop target in other Pimcore editors (e.g. relation, image or WYSIWYG fields).

Depending on your permissions, you can publish or unpublish an item through its context menu in the bookmark list too.

Add, Rename or Delete Items From a Bookmark List​

info

Only users with write permission can apply changes on a bookmark list. See the Permissions section for details.

Once you created your new bookmark list, you can fill it in with items (Assets, Data Objects, Documents, or folders) from the Pimcore element trees. This can be done by drag & drop or copy-paste from the element tree to the bookmark list.

info

Pimcore provides a separate clipboard per element tree. This means that every time you copy an element from a tree, this one is saved in the according clipboard. When you want to paste an element to your bookmark list, you can either paste the content of one of your clipboards (containing an Asset, a Data Object, a Document or an element folder) or paste the content of all of them at the same time.

The content organization of the folders added from the element trees to a bookmark list cannot be changed. However, you can create your own folders (through the context menu) that will exist only in your bookmark list and that you can organize according to your needs. Those folders will appear on top of your bookmark list by default.

info

Each folder added from an element tree has its own icon depending on its content:

  • for Documents;
  • for Assets;
  • for Data Objects;
  • for custom folders.

With bookmark lists, you also have the possibility to add the same item at different levels (folders) of a single tree (in the sample below, the same Data Objects appear at two different levels of the same custom folder Lights).

With the right permissions, you can rename or remove an item from a bookmark list (or your own folders) from the context menu (Rename or Remove from list ).

caution

Be aware that changing the name of an item in a bookmark list will also update this item's name in its corresponding Pimcore element tree (and thus update every occurrence).

Sort a Bookmark List's Items​

The bookmark list's sorting behavior is as follows:

  • sorted by name: the bookmark list will automatically refresh whenever you drop a new item. You can then find the newly added item in its right place according to its name.
  • sorted manually: the bookmark list's order will remain as it is, unless you change it manually. You can drop an item from the Pimcore element trees directly where you want it to be at the first level of your bookmark list.

In both cases, you cannot change the content of folders from the element trees. If you need a customized structure, you can create a new folder that will exist only in your bookmark list through a right-click in your bookmark list menu. You can then add any items and sort them by drag & drop from one position to another in your newly created folder, if the whole list is sorted manually.

caution

Be aware that, if you need to change the name or the sorting criteria of an opened bookmark list, this change will be effective only by reloading the backend or closing and opening the list again.

Delete a Bookmark List​

If you own a bookmark list, you can delete it from the grid by clicking the delete icon.

caution

An administrator can delete a bookmark list without being the list owner through the Show all Bookmark Lists in System option. Be aware that, at the moment, the Delete Bookmark List dialog is the same even if the user is not the list owner.
